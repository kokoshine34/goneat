# Go & Eat Travel v1.0

Bilingual (English / Burmese) static website starter with four travel product sections and configurable affiliate provider links.

## Included
- Responsive homepage and booking interface
- English / Burmese language switcher
- Flights, hotels, attractions and train search forms
- Trip.com integration configuration for all four categories
- Agoda hotel integration configuration
- Partner selection modal
- Affiliate disclosure and external booking notice
- No payment collection, login, passport data or booking database

## Before deployment
1. Open `affiliate-config.js`.
2. Paste only the exact affiliate URLs generated by your approved Trip.com and Agoda partner dashboards.
3. Follow `integrations/README.md` to add approved provider widgets.
4. Replace generic social links with the official Go & Eat profile URLs.
5. Review Burmese copy and all images / image licences.
6. Test the partner links and tracking before making the site public.

The search form currently validates the visitor's selected fields and then presents configured partner links. It does not yet send route/date/guest criteria to providers. Provider-specific search widgets or approved APIs are required for that functionality. No provider-specific URL pattern is guessed or fabricated.

## Deploy on Cloudflare Pages
- Framework preset: None
- Build command: leave empty
- Build output directory: `/` (repository root, shown as `.` in some dashboards)
- Add your custom domain in Workers & Pages > your project > Custom domains.

## Security
All affiliate links in `affiliate-config.js` are public. Never place API secrets, private tokens, passwords or customer payment details in this file. Any future API integration must run server-side and use Cloudflare secrets.
